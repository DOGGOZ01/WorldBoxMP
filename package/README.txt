WorldBoxMP 0.18.0 - online WorldBox for up to 4 players
=======================================================

REQUIREMENTS
- WorldBox on Steam, the same version for every player
- NeoModLoader: https://steamcommunity.com/sharedfiles/filedetails/?id=3080294469
- WorldBoxMP 0.18.0 for every player
- The Steam overlay turned on (needed for invites)

INSTALL
1. Install NeoModLoader, start WorldBox once and close it.
2. Copy the WorldBoxMP folder from this archive into <WorldBox>\Mods
   (Steam -> WorldBox -> Manage -> Browse local files).
3. Start WorldBox. A Multiplayer tab appears in the powers bar.

HOST
Open your world, press Multiplayer -> Create lobby, choose the settings and press Open lobby.
Send friends the invite code or press Invite friend.

JOIN
Press Multiplayer -> Join and pick a lobby, or join by code or IP. Steam invites work too.

KEYS
T            chat
Alt + click  ping the map
F9           get the whole world from the host again
F6           leave the lobby

While a lobby is open, worlds can't be loaded or created. Press Exit Lobby first.

PERFORMANCE
Recommended: a standard size world or smaller and no more than 2000 units.
If it lags, the host can set tick_ms=100 in Mods\WorldBoxMP\WorldBoxMP.cfg.

Logs: Mods\WorldBoxMP\logs
More: https://github.com/DOGGOZ01/WorldBoxMP
